# Compliance matrix

Status is PASS only where a measured result meets the PDF bar. BLOCKED means the physical input is absent, the source is FARO or another external reference, or the photo scale is still the 1.40 m prior. FAIL means a measurement was made and it missed the bar. DEGRADED means the pipeline ran and did not produce a valid measurement. A synthetic fixture is not a physical pass.
