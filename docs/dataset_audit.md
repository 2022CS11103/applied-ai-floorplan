# External dataset audit

Checked against the official dataset pages and papers on 5 Oct 2026. A cell is blank only when that source does not state the fact. This audit does not treat a public set as the company laser/tape benchmark.

Class is what the files can actually feed:

- A: depth or RGB-D plus poses in a form close to `run.py` lidar or video, and a public or approved download that a single machine can hold.
- B: one module (openings, photo panoramas, or a laser cloud) but not a phone capture.
- C: geometry or synthetic layout only. Not a capture for `run.py`.
- D: not useful for this assessment.

The requested A-list was changed where the documentation disagrees. ZInD is 360° panoramas, not a pinhole LiDAR walk. LaserDoors is single doors, not a multi-room plan. ISPRS TUB1/TUB2 are trolley or handheld laser clouds plus a trajectory, not camera intrinsics and depth images.
